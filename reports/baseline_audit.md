# 基线实现核对：通过，保留简化实现的明确边界

核对日期：2026-10-05。参考为 **Anomalib 2.2.0**，固定提交 `592aafc373091dda8206510a0853eb11c8e4099d`。独立环境实际安装并运行了该版本，相关七个源码文件与固定提交逐一比对一致；未使用手写替代模型冒充框架结果。

**结论：在本轮覆盖的数据和配置下，未发现当前简化基线的核心计算错误。原 A/B 试验仍然有效，无需替换或选择性重跑。它与 Anomalib 默认 PatchCore 存在已量化的算法差异，因此继续称为“简化 PatchCore 基线”，不能标为默认框架或论文数值复现。**

## 核对范围与控制变量

- bottle，seed=42，5 张正常原图；A 为原图，B 另加 15 个增强副本。
- 原有 42 张干净正常校准图，以及 16 张开发图的 5 个条件。
- 共 269 次输入特征核对、244 次评分核对，包含相同原图的不同扰动版本，不是 269/244 张独立原图。
- 固定 ImageNet ResNet18 权重、layer2/layer3、224×224、RGB 数值和归一化。将同一权重逐项复制到 Anomalib 的 timm ResNet18；没有下载另一套 timm 默认权重。
- 原权重文件缺少较新 BatchNorm 的 `num_batches_tracked` 计数器，按 Torchvision 加载行为补零；所有计算参数及均值/方差缓冲完全相同，模型处于 eval。
- 首先共用原有记忆库，隔离特征与评分差异；再运行参考实现自己的采样器，检查固定容量和结果变化。
- 最终测试集未参与模型评估。

## 逐项结果

| 核对项 | 当前实现 | Anomalib 2.2.0 对照 | 结论 |
|---|---|---|---|
| 输入 | PIL 直接缩放 224，RGB，ImageNet 归一化 | 本轮提供相同已归一化输入；其 Lightning 默认输入为 256，可选中心裁剪 | 控制一致；未宣称默认预处理相同 |
| 骨干层输出 | Torchvision ResNet18，layer2/layer3 | timm ResNet18 加载完全相同权重，另用 Torchvision FX 独立提取交叉核对 | 最大绝对差 0 |
| 局部池化与特征对齐 | 3×3 均值池化，layer3 双线性上采样，拼接后展平 | 相同，双线性插值默认 align_corners=False | 拼接特征最大绝对差 0 |
| 最近邻 | 分块 torch.cdist，欧氏 1-NN | 范数/矩阵乘法计算欧氏距离后 min | 最大绝对差 0.000163766，满足预设容差 |
| 图像分数（共用记忆库，k=1） | 最大 patch 距离 | `num_neighbors=1` 时为最大 patch 距离 | 最大绝对差 0.000005365 |
| 图像分数（参考默认 k=9） | 无重加权 | 根据近邻支持集合进行 softmax 重加权 | 最大差约 0.392134，是有意简化造成的差异 |
| 异常图 | 双线性上采样，无平滑 | 最近邻上采样 + sigma=4、33×33 Gaussian、reflect padding | 最大像素分数差约 0.290247；不能要求图像完全一致 |
| 采样投影 | 固定 64 维高斯投影 | eps=0.9 的稀疏投影，A 为 204 维，B 为 238 维 | 不同采样算法配置 |
| 贪心起点 | 随机初始点计入容量，随后选最远点 | 先用随机点更新距离，再选择首个最远点 | 不保证相同种子选出相同索引 |
| 最终记忆库 | A/B 各 1,000 向量 | 按候选数量换算比例，核实 A/B 实际各 1,000 向量 | 容量公平，未重复填充 |
| 阈值 | 干净正常校准的 95% linear 分位数 | 本轮各参考评分方案也按同一规则单独校准 | 光照间固定；不使用框架自动阈值/归一化 |
| AUROC | 项目平均秩实现 | scikit-learn roc_auc_score 独立复核图像/像素结果 | 全部在 1e-12 以内一致 |

数值验收容差在运行前写入脚本：特征 atol=1e-6、rtol=1e-6；距离/分数 atol=5e-4、rtol=2e-5。距离的微小差异来自两种 float32 欧氏距离计算路径，不能要求每个 patch 逐位相等。

## 原有结果的可复现性

| 方法 | 特征核对次数 | 评分核对次数 | 原记忆库重建 | 原逐图分数最大差 | 本地/参考采样索引交集 |
|---|---:|---:|---|---:|---:|
| A | 127 | 122 | 索引及向量精确一致 | 0 | 417 / 1,000 |
| B | 142 | 122 | 索引及向量精确一致 | 0 | 185 / 1,000 |

上述交集仅说明两种采样得到不同集合，不能用来判断哪一种更优。主项目依赖快照在核对前后完全相同。独立核对环境 `pip check` 通过。
