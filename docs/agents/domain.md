# 领域文档

本项目采用单一领域上下文。以下路径均相对于仓库根目录。

讨论项目术语、设计决定或探索相关代码时，阅读存在的 `GLOSSARY.md` 和 `docs/adr/` 中与当前任务有关的记录。

文档缺失时直接继续。术语或设计决定实际明确后，由 domain-modeling 等相关技能按需创建。

任务标题、代码名称、测试和设计讨论使用术语表定义的名称。概念未定义时，判断是否需要引入新概念，并记录待澄清问题。

新方案与已有 ADR 冲突时，指出对应记录及重新讨论的理由。领域文档补充已确认的决定，研究边界继续以 `docs/formal_protocol_v1.md` 为准。
